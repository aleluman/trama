# React Compiler without Babel

Trama uses `oxc-transform-react` 0.145.0 to compile the React binding. TypeScript emits the core and declarations, and `@vitejs/plugin-react` 6.1.1 enables the Oxc compiler in the guide. This version of Oxc is compatible with the optional peer dependency range declared by the plugin. React recommends distributing compiled libraries. React 19 includes the runtime the binding needs. [Plugin manifest](https://github.com/vitejs/vite-plugin-react/blob/plugin-react%406.1.1/packages/plugin-react/package.json) · [Compiling libraries](https://react.dev/reference/react-compiler/compiling-libraries) · [Definitions and sessions](../technical.html#capability-define)

## Options examined

- **Oxc** integrates the compiler in Rust and runs it before transforming JSX and stripping TypeScript types. It fits into the package build and the Vite guide build. Oxc documents the integration as experimental. [React Compiler in Oxc](https://oxc.rs/docs/guide/usage/transformer/react-compiler.html) · [Transform order](https://oxc.rs/docs/guide/usage/transformer)
- **SWC** integrates the native compiler into Rspack and Rsbuild. The SWC plugin for Vite exposed a low-level setting. Adopting that path would have required changing Trama's build configuration. [Rspack 2.1](https://rspack.rs/blog/announcing-2-1) · [Rsbuild](https://rsbuild.rs/plugins/list/plugin-react#reactcompiler) · [SWC plugin for Vite](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc/README.md)
- **Babel** was available in Vite through `reactCompilerPreset()`, with `@rolldown/plugin-babel`, `@babel/core`, and `babel-plugin-react-compiler`. [React plugin for Vite](https://github.com/vitejs/vite-plugin-react/blob/plugin-react%406.1.1/packages/plugin-react/README.md)

## Evidence from September 20, 2026

Versions 0.145.0 and 0.150.0 transformed the React entry and sample code without fatal errors or diagnostics. The output contained `react/compiler-runtime` caches. With 0.145.0, 26 public behavior tests passed, including render counts, and five tests against the built package passed. For the September 20, 2026 test, the package was built manually. Running Trama's `prepack` at that revision would have let `tsc` overwrite Oxc's output, so the test did not cover normal packaging at that revision. Plugin 6.1.1 declared `^0.145.0` as an optional peer dependency and `^0.147.0` in its development dependencies, two different ranges for a 0.x package. Verification of 0.150.0 was limited to the transform. Comparative timings and HMR were outside verification for both versions.

`createReactBinding` declares a component and a hook inside a factory, a pattern flagged by `component-hook-factories`. In the variant that omitted `memo(Field)`, Oxc left the nested function intact and memoized the element returned by `useFieldRenderer`. Nine React and rendering tests passed in that variant. The counters recorded calls to the application's renderers. Calls to `Field` after its parent updated were outside that measurement. [`component-hook-factories` rule](https://react.dev/reference/eslint-plugin-react-hooks/lints/component-hook-factories)
